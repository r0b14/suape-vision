Guia de Uso — API SUAPE Vision

URL Base

Todos os endpoints partem de https://suapevision.vercel.app.

Endpoints

GET /api/dados

Retorna todos os registros de navios em formato JSON.

GET /api/dados/id/<id>

Filtra pelo ID do navio. Ex.: /api/dados/id/GH89J

GET /api/dados/data/<data>

Filtra pela data no formato YYYY-MM-DD. Ex.: /api/dados/data/2024-04-20

GET /api/dados/id/<id>/data/<data>

Combinação de filtros por ID e data. Ex.: /api/dados/id/ZX56O/data/2024-01-01

GET /download_csv

Faz o download dos dados em formato CSV.

Formato da Resposta

Todas as respostas são JSON. Quando nenhum registro é encontrado, o status 404 é retornado com o campo erro.

{ "erro": "Nenhum registro encontrado." }

Exemplos

cURL

curl https://suapevision.vercel.app/api/dados
curl https://suapevision.vercel.app/api/dados/id/GH89J
curl https://suapevision.vercel.app/api/dados/data/2024-04-20
curl https://suapevision.vercel.app/api/dados/id/ZX56O/data/2024-01-01

JavaScript (Fetch API)

const res = await fetch('https://suapevision.vercel.app/api/dados');
const dados = await res.json();
console.log(dados);

Python

import requests

dados = requests.get('https://suapevision.vercel.app/api/dados').json()
print(dados)

Java

import java.io.*;
import java.net.*;

public class ApiExample {
    public static void main(String[] args) throws Exception {
        URL url = new URL("https://suapevision.vercel.app/api/dados");
        HttpURLConnection conn = (HttpURLConnection) url.openConnection();
        conn.setRequestMethod("GET");

        BufferedReader in = new BufferedReader(new InputStreamReader(conn.getInputStream()));
        StringBuilder response = new StringBuilder();
        String line;
        while ((line = in.readLine()) != null) response.append(line);
        in.close();

        System.out.println(response);
    }
}
